# Feature-Engineering---Review-Stardew-Valley-from-Steam-Web-
Proyek web scraping, preprocessing, dan 5 metode feature engineering pada review game Stardew Valley dari Steam. Data diambil melalui HTML scraping dan Steam API, dipreproses lalu divisualisasikan dengan WordCloud dan grafik Voted_up, kemudian diubah dengan One Hot Encoding, Bag of Words, TF-IDF, Word2Vec, dan FastText.
